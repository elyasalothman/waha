# واحة · Waha

واحة OS — نظام يومي عربي هادئ: **ظل اليوم** للصلاة، وطقس كامل، وصندوق عائلة محلي، ومتجر ميزات. الحساب اختياري.

## الوضعان

- **أفراد** — مواقيت أم القرى، أذكار، وثائق، فواتير المنزل، زكاة، ذهب، ألعاب
- **عمل** — عملاء، عروض سعر، فاتورة برمز هيئة الزكاة (TLV)، رخص المنشأة، رواتب بعد التأمينات، بوابات قوى والزكاة

التبديل من المفتاح أعلى القائمة. العربية افتراضياً، مع إنجليزي بنقرة.

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:8080`. للبناء:

```bash
npm run typecheck
npm run build
```

## التقنية

TanStack Start وReact 19 وTailwind v4. البيانات في `localStorage`. مواقيت الصلاة حسب أم القرى (`adhan`)، الطقس من Open-Meteo، والعملات من Frankfurter.
