# محسن المحلي على الكمبيوتر

الإصدار 0.2.0 يستخدم نواة واحة المشتركة، ثم نموذجك المحلي عند غموض الأمر. إذا لم يوجد نموذج فالحساب والتحويلات والملاحظات وPDF والسيرة تبقى متاحة. الوضع الافتراضي «محلي ثم سحابة»: إجابة محلية أولًا، والسحابة عند غياب النموذج أو تعذّر اتصاله. اختر «محلي فقط» لمنع إجابات السحابة؛ أدوات الطقس والأخبار الخارجية تظل تحتاج شبكة عند طلبها صراحةً.

## تشغيل نموذج على ويندوز وماك

1. ثبّت [Ollama](https://ollama.com/download) وافتحه.
2. افتح Terminal / PowerShell ونفّذ `ollama pull qwen2.5:3b` بنفسك. زر «نسخ أمر التثبيت» ينسخ الأمر فقط، ولا يشغّله ولا ينزّل أي شيء.
3. افتح محسن بـ Ctrl+K ثم إعدادات الذكاء، واختر «إعادة الاكتشاف» والنموذج.

[Qwen2.5:3b](https://ollama.com/library/qwen2.5) حجمه نحو 1.9 GB، مناسب كبداية للعربية. خصّص عمليًا 4 GB ذاكرة متاحة، ويفضّل جهاز RAM 8 GB أو أكثر؛ هذه ميزانية تقريبية تتغير مع طول السياق والتكميم. نموذج 7b حجمه نحو 4.7 GB ويتطلب ذاكرة أكبر (يفضّل جهاز RAM 16 GB). يمكن اختيار gemma3:4b أو نموذج ALLaM/Jais GGUF عند توفره في خادمك؛ الجودة العربية تعتمد على النموذج والجهاز.

بديلًا عن Ollama: شغّل [llama.cpp server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) على `127.0.0.1:8080` أو الخادم المحلي في [LM Studio](https://lmstudio.ai/docs/developer) على `127.0.0.1:1234`. فعّل CORS للسماح بأصل تطبيق Tauri عند استخدام fetch من الواجهة. لا تربط الخادم بعنوان عام ولا تضع مفاتيح في واحة. يستعلم التطبيق عن `/api/tags` في Ollama وعن `/v1/models` في الخادمين الآخرين، ثم يستخدم `/api/chat` أو `/v1/chat/completions` مع `stream:false`. لا يدعم عناوين خوادم عشوائية.

## التنفيذ والخصوصية

- المحلل الحتمي المشترك يختار الأدوات أولًا؛ عند فشله يُطلب من النموذج المحلي JSON وفق سجل الأدوات، مع تحقق Zod صارم وقائمة أدوات محدودة. الرد غير الصالح أو الأداة الممنوعة لا يُنفّذان ولا يتحولان إلى أمر shell.
- المحادثة والتلخيص والكتابة عبر نموذجك المحلي موسومة «من نموذجك المحلي — بلا مصدر». الذاكرة تُمرَّر لهذا النموذج فقط. مخطّط الأدوات يستقبل الطلب والسجل فقط.
- وضع السحابة يرسل `{message: السؤال, messages: []}` إلى si.alhajda.com، بلا ذاكرة ولا سجل محادثة ولا ملفات. الرد السحابي نص فقط؛ لا ينفّذ التطبيق أوامر واردة منه. تظهر «موثّق ✓» فقط عند وجود مصدر HTTPS صالح، والمصدر نفسه لا يُفتح إلا بتأكيد وضمن قائمة الروابط المسموحة.
- في Tauri تحفظ الذاكرة والملاحظات والتذكيرات والتقييمات والعبارات الفاشلة ونتيجة «قيّم محسن» والإعدادات في `mohsen.json` داخل appDataDir. معاينة المتصفح تستخدم localStorage فقط. لا تُرسل التقييمات تلقائيًا؛ زر GitHub اختياري ويفتح نموذج ملاحظة فارغًا بتأكيد.
- الفتح الخارجي محصور بواحة ومختبر الرياضيات ونموذج ملاحظات GitHub. البرامج: حاسبة النظام، المفكرة/TextEdit، ومجلدا التنزيلات والمستندات فقط، عبر أوامر Rust ثابتة. لينكس يفتح المجلدات فقط؛ تطبيقات النظام تعرض رسالة بديلة.
- الحساب والتنقل الداخلي بلا تأكيد. حفظ الملاحظات والتذكيرات والذاكرة والمسح بتأكيد. الفتح الخارجي والبرامج والملفات النصية و«حفظ باسم» بتأكيد، مع «اسمح دائمًا» للأداة المتوسطة فقط ويمكن سحبه من الإعدادات. الحفظ النصي الجديد يستخدم createNew ويرفض استبدال ملف موجود. لا حذف ملفات ولا إيقاف جهاز ولا shell حر.
- تلخيص ملف يدعم txt/md حتى 100 KB، باختيار الملف من نافذة النظام وإرساله للمحلي فقط. زر «حفظ النص / الملاحظات باسم» يحفظ نص الحقل أو الملاحظات؛ لتصدير جواب انسخه للحقل.
- التذكيرات تُراجع كل 10 ثوانٍ والتطبيق مفتوح، وتظهر داخله، مع إشعار نظام إن أذن المستخدم. لا خدمة خلفية أو ضمان إشعار بعد إغلاق التطبيق. عند إعادة فتحه تظهر التذكيرات المستحقة غير المعروضة.

| الأداة | بلا إنترنت | تحتاج شبكة |
|---|---|---|
| الحساب، حل معادلات بسيطة، التحويلات والنسب | نعم | لا |
| PDF والسيرة | نعم | لا |
| الملاحظات والتذكيرات والذاكرة والتقييم | نعم | لا |
| تطبيقات النظام والمجلدات وحفظ/قراءة نص | نعم، داخل Tauri | لا |
| المحادثة والتلخيص والكتابة محليًا | نعم بعد تثبيت نموذج | تحميل النموذج أول مرة فقط، يدويًا |
| طقس Open-Meteo والأخبار | لا | نعم عند طلب الأداة |
| إجابات si.alhajda.com | لا | نعم حسب الوضع المختار |
| أقسام الويب والمختبر وملاحظات GitHub | لا | تفتح المتصفح بعد الموافقة |

## التحقق والحدود

`npm test` يشمل النواة والمضيف واكتشاف الخوادم، اختيار النموذج، الخطط الصالحة/المرفوضة، الانقطاع، التأكيد، التخزين، خصوصية السحابة، والمصادر. الأمر «قيّم محسن» يشغّل corpus النواة محليًا ويحفظ دقتها؛ هو قياس فهم النواة لا جودة النموذج أو نجاح أدوات النظام. فحص Playwright في `docs/audits/desktop-agent.json` يستخدم مضيف الويب البديل عند 1280×800؛ ليس اختبارًا لمثبت Tauri. لم يتوفر Ollama أو Rust في بيئة هذه الجولة؛ اتصال النموذج الحقيقي، نوافذ النظام والإشعارات تتطلب تجربة جهاز فعلية. CI يبني Rust والمثبتات الثلاثة كمسودة إصدار غير منشورة.
