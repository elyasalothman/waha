# نواة محسن المشتركة

`src/lib/agent/planner.ts` تصدّر `plan(text, ctx) → Plan` و`executePlan(plan, host, options)`؛ تستورد ملفات TypeScript بمسارات نسبية وامتداد `.ts` ولا تتطلب React أو DOM. السياق الاختياري `{city, now}` محلي ولا يضاف إلى سؤال محسن. تتضمن الخطة `steps` ولكل خطوة `command`, `description`, `status`, `id`، وثقة رقمية واقتراحات عند الغموض. لا ينفذ المضيف خطة ذات ثقة منخفضة.

`registry.ts` يصدّر `ToolRegistry` و`registry` و`validateCommand`. كل مخطط Zod صارم: الأدوات غير المعروفة والحقول الإضافية مرفوضة. الأدوات الثماني عشرة الأصلية محفوظة للتوافق، و`math` يستقبل `{expr}`. الحقل `changing` يتطلب تأكيد الخطوة، ويشمل الروابط الخارجية والإعدادات والحفظ والحذف. لا شراء ولا نشر ولا إرسال رسائل.

المضيف يوفّر `execute(command): Promise<unknown>`، ويمكنه توفير `navigate`, `openExternal`, `storage`, `notify`, `fetch`. يفصل المضيف التخزين والإشعارات والاتصال بالمنصة عن النواة. `executePlan` يتسلسل ولا يتجاوز خطوة فاشلة أو غير مؤكدة. أعد تمرير الخطة الناتجة مع `confirmedStepIds: [step.id]` بعد موافقة صريحة؛ خطوات `done` لا تعاد. `onStep` ينشر تحديثات الحالة. لا تحفظ الموافقة العامة لجميع الخطوات المستقبلية.

للسطح المكتبي: `node scripts/export-agent-core.mjs /path/to/core`. ينسخ السكربت الاعتماديات النسبية مع النواة وREADME، ويستخدم واجهات تخزين بنيوية لا تحتاج DOM. الاعتماد الخارجي المطلوب Zod. لا ينسخ مشغل React أو مفاتيح أو ملفات بيئة. احتفظ بنفس بنية المجلدات؛ نقطة الدخول `agent/planner.ts`.

التقييم: `node scripts/agent-eval.mjs` يقارن الأداة والمعاملات المتوقعة في 150 عبارة عربية على الأقل، ويطبع نتيجة لكل أداة ويرفض الدقة الأقل من 95%. الاختبارات المستقلة تتحقق من التسلسل والتأكيد والتقسيم ورفض مدخلات الأدوات.
