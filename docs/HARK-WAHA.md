- رف الكتب يعرض تعذّر التحقق من الحساب مع إعادة المحاولة، مع بقاء استخدام الكتب المحلية متاحًا.

## PWA والعمل دون اتصال

- تسجيل Service Worker بعد حدث load في الإنتاج فقط، مع تحديث ملف العامل دون HTTP cache.
- تخزين الأصول العامة والصفحات العامة المحددة التي زارها المستخدم؛ network-first للمستندات وcache-first للأصول ذات الأسماء المرقّمة. الصفحة غير المحفوظة تعرض `offline.html` عربية مع إعادة المحاولة والرئيسية.
- لا تُخزّن API أو المصادقة أو صفحات الكتب الخاصة أو HTML رف الكتب في CacheStorage؛ تبقى ملفات الكتب المحلية في IndexedDB وفق سلوكها السابق. هذا ليس تنزيلًا كاملًا لجميع الكتب والفصول دون اتصال.
- فشل الكتابة في cache (مثل امتلاء التخزين) لا يحوّل استجابة الشبكة الناجحة إلى خطأ.

## ما بقي قبل اعتبار iOS جاهزًا

1. إكمال إعداد المصادقة وقاعدة الإنتاج أعلاه، مع اختبارات الحساب الحقيقي ورفض الأصول غير المصرح بها وانتهاء الجلسات. نشر الكتب العامة يبقى غير جاهز قبل ذلك.
2. فصل HTML الفصول وفهرس بحث كتاب الهجدة عن حزمة القارئ الحالية (~1.4MiB)، وإنتاج صور جوال مضغوطة (الغلاف الأصلي ~550KB)، ثم قياس cold-load مضبوط بشبكة جوال وCPU بطيئين. القراءات الحالية ليست Lighthouse ولا مقارنة مخبرية للسرعة.
3. إصلاح اختبارات القالب باستخدام fixtures مستقلة، والتحقق من المصادر الخارجية الثلاثة المذكورة في الجولة الأولى.
4. اختبار VoiceOver وSafari وiPhone فعلي: لوحة المفاتيح العربية وRTL والتركيز، safe areas، واستعادة موضع القراءة بعد تعليق التطبيق، والتعامل مع فقد الاتصال.
5. **Capacitor موجود أصلًا**: `com.alhajda.waha` وواجهة `ios/App`. الإعداد الحالي يحمّل الموقع البعيد؛ Service Worker الخاص بـPWA لا يثبت وجود fallback صالح داخل WKWebView. يلزم تجربة فشل الشبكة عند الإقلاع، وتصميم fallback محلي فعلي. `scripts/sync-www.mjs` يبحث عن index.html؛ خرج SSR لا يوفر بالضرورة تطبيقًا محليًا ثابتًا، وقد يختار `native/www-fallback` فقط. لا تعتبر `cap sync` دليلًا أن الموقع كله يعمل محليًا.
6. **Codemagic موجود أصلًا**: مراجعة توفر إصدار Xcode المثبت في `codemagic.yaml`، تكامل App Store Connect، شهادة وتوقيع وبروفايل الحزمة ورقم بناء متزايد؛ ثم تنفيذ archive على macOS ورفع TestFlight واختباره. لم يُنفّذ archive أو رفع iOS من Linux في هذه الجولة. مراجعة تشغيل workflow التلقائي على main قبل جولة إصدار مستقلة.
7. مراجعة الإشعارات المحلية للصلاة وموافقتها وإعادة جدولتها، روابط النطاقات والتنقل الخارجي، سياسة الخصوصية وبيانات App Store وحذف الحساب إن فُعّل. وجود ملفات Capacitor/Codemagic وحده لا يعني جاهزية المتجر.
