## PWA والعمل دون اتصال

- تسجيل Service Worker بعد حدث load في الإنتاج فقط، مع تحديث ملف العامل دون HTTP cache.
- تخزين الأصول العامة والصفحات العامة المحددة التي زارها المستخدم؛ network-first للمستندات وcache-first للأصول ذات الأسماء المرقّمة. الصفحة غير المحفوظة تعرض `offline.html` عربية مع إعادة المحاولة والرئيسية.
- لا تُخزّن API أو المصادقة أو صفحات الكتب الخاصة أو HTML رف الكتب في CacheStorage؛ تبقى ملفات الكتب المحلية في IndexedDB وفق سلوكها السابق. هذا ليس تنزيلًا كاملًا لجميع الكتب والفصول دون اتصال.
- فشل الكتابة في cache (مثل امتلاء التخزين) لا يحوّل استجابة الشبكة الناجحة إلى خطأ.

1. إكمال إعداد المصادقة وقاعدة الإنتاج أعلاه، مع اختبارات الحساب الحقيقي ورفض الأصول غير المصرح بها وانتهاء الجلسات. نشر الكتب العامة يبقى غير جاهز قبل ذلك.
