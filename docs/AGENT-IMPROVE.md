# تحسين محسن

النواة لا تعدّل كودها وقت التشغيل. التطور هنا دورة مراجعة واختبارات وإصدارات قابلة للرجوع، وليس تدريبًا مستمرًا أو تشغيلًا ذاتيًا خارج الجلسة.

كل تقييم 👍/👎 وعبارة «ما فهمني» يحفظ على الجهاز فقط، بحد 200 سجل بعد تطبيع الأرقام وإخفاء البريد والأرقام الطويلة. لا تعد هذه الإزالة ضمان إخفاء كل معلومة شخصية؛ يعرض المستخدم التقرير ويراجعه قبل المشاركة. خيار «ساعد محسن يتحسّن» مطفأ افتراضيًا. التفعيل لا يرسل شيئًا: يتيح نسخ التقرير أو فتح مسودة issue عامة، ثم المستخدم هو من ينشرها.

الدورة الأسبوعية المقترحة عند تشغيل Hark المصرح به: قراءة issues ذات agent-feedback، تشغيل `node scripts/agent-eval.mjs`، فرز الفشل، إضافة حالات واقعية ومرادفات واختبارات تمييز سلبية، إصلاح محدود، ثم lint/typecheck/test/build وفحص متصفح ونشر مصرح به والتحقق الحي. لا توجد جدولة جديدة أو إرسال تلقائي في هذه الجولة.

ذاكرة الاسم والمدينة والتفضيلات محلية، ولا تدخل طلب محسن. يرسل `/api/agent` السؤال وحده مع سجل فارغ إلى خدمة محسن القائمة. الروابط والمصادر بيانات غير موثوقة؛ تعرض نصًا، وتفتح HTTPS بتأكيد. لا شراء ولا نشر ولا إرسال رسائل، ولا مفاتيح جديدة.
