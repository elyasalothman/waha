# تشغيل منصة الكتب

- `/books`: نصوص مداد الأصلية وكتب المالك المنشورة والمسودات المحلية، بحث وتصنيف عمر ومؤلف ورفّي ومعرفة اليوم ومسارات العمر.
- `/studio`: رفع PDF نصي أو EPUB أو DOCX أو TXT حتى 20MiB، أو لصق نص حتى مليون حرف؛ استخراج النص وفصول قابلة لإعادة التدفق، مع نص قابل للتصحيح قبل الحفظ. تنسيق الصور والجداول والحواشي المعقدة لا يُحفظ في التحويل النصي؛ راجع المعاينة. PDF المصوّر يحتاج OCR مسبقًا، ولا يُنشر نص ناقص بصمت. EPUB المشفّر مرفوض.
- الغلاف صورة PNG/JPEG/WebP حتى 250KB. عنوان ومؤلف وتصنيف وعمر، وتأكيد صريح لحقوق النشر قبل طلب النشر العام.
- المسودة تحفظ في IndexedDB مستقل عن مكتبة PDF الخاصة الحالية؛ حذفها متاح من الرف. موضع الفقرة والفصل وحجم الخط والوضع الليلي محفوظة محليًا. لا تُرفع الملفات الأصلية أو المسودات إلى الخادم عند المعاينة.
- الكتب العامة تحفظ في Postgres المعتمد عبر `DATABASE_URL`: البيانات الوصفية والغلاف والفصول النصية في `public_books`. لا يوجد fallback إنتاجي إلى قاعدة مؤقتة. نصوص مداد الثابتة مستضافة في JSON منفصل لكل نص، مع توثيق المصدر في `MIDAD-IMPORT.md`.

## تفعيل نشر المالك

مشروع Vercel بلا إعدادات إنتاج وقت هذه الجولة؛ لذلك لا يمكن إكمال نشر كتاب عام واختباره بحساب حقيقي قبل توفيرها.

1. إعداد `DATABASE_URL` و`BETTER_AUTH_SECRET` و`BETTER_AUTH_URL=https://waha.hajdah.com` وبيانات OAuth `GROK_AUTH_CLIENT_ID` و`GROK_AUTH_CLIENT_SECRET` وتسجيل callback لدى الموفر كما في توثيق المصادقة. لا تستخدم بيانات المعاينة السرية في الإنتاج.
2. تطبيق مخطط المصادقة `migrations/auth/0001_auth.sql` وفق إجراء قاعدة الإنتاج، ثم `npm run db:migrate` لتطبيق `migrations/0001_public_books.sql` على القاعدة نفسها. سكربت الترحيل لا يطبّق مخطط auth الفرعي تلقائيًا. البناء لا ينفذ ترحيل الإنتاج.
3. تعيين `BOOKS_ADMIN_USER_IDS` إلى معرّف حساب المالك الفعلي في Better Auth (قائمة IDs مفصولة بفواصل)، ثم إعادة النشر. PIN الإدارة المحلي لا يمنح حق النشر.
4. اختبار دخول المالك، رفع كتاب أصلي ومعاينته ثم نشره؛ التحقق من ظهور الكتاب في متصفح آخر واستمرار المحتوى بعد نشر جديد. اختبار حساب غير مدير وطلب دون جلسة وأصل غير مسموح: يجب رفضها. لا تعتبر اختبار رفض الزائر دليلًا على نجاح نشر المالك.

`GET /api/books` يعرض بيانات الرف. `GET /api/books?id=UUID` يعرض الكتاب. `POST /api/books` يتحقق من إعدادات الإنتاج والأصل وجلسة Better Auth وقائمة المدير وحقوق النشر وبنية المحتوى وحدود الحجم؛ يُنشئ UUID على الخادم. API لا يدخل CacheStorage؛ القارئ المحلي يبقى مستقلاً عن خدمة المصادقة.

## إعادة فحص الجوال

`AUDIT_IGNORE_HTTPS_ERRORS=1 node scripts/audit-books.mjs https://waha.hajdah.com /tmp/waha-books-live`

تجاهل شهادة HTTPS في الاختبار فقط مطلوب لوكيل شبكة هذه البيئة؛ ليس إعدادًا في التطبيق. ملفات الاختبار ينشئها السكربت بنفسه ولا تتضمن كتب طرف ثالث. يختبر الصيغ الأربع والفهرس وحجم الخط والليل واستعادة الموضع والرف ورفض النشر المجهول و390px. المعاينات محلية داخل سياق الاختبار وتختفي بإغلاقه. لم يُختبر VoiceOver أو جهاز iPhone فعلي.
