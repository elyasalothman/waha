# الصفحة التعريفية وحساب واحة

- `/` صفحة تسويقية للزائر، وتحوّل صاحب الجلسة الحقيقية إلى `/today` بعد التحقق من الجلسة. `/welcome` متاح دائمًا. `/today` متاح للضيف أيضًا.
- `/register?mode=signup` و`signin` و`forgot` و`reset` تتحدث مع Better Auth نفسه؛ لا حسابات ضيوف مصطنعة. التسجيل الناجح ينتقل إلى `/onboarding` ثم `/today`، والدخول إلى `/today` مباشرة.
- الاهتمامات تحفظ على هذا المتصفح لكل معرّف حساب، أو للضيف، وتظهر كاختصارات في «يومي». لا ادعاء بمزامنتها إلى حساب أو جهاز آخر.
- `/api/auth-status` يعيد قدرات الخدمة فقط دون قيم أو أسرار، مع `Cache-Control: no-store`. زر Google لا يظهر إلا عند تهيئة عميل OAuth الحقيقي. مسارات OAuth ترفض بيانات عميل المعاينة في الإنتاج عند غياب إعدادات العميل الفعلي.

## تفعيل الحسابات

فحص Vercel لهذه الجولة: `envs=[]`, `hiddenProductionEnvCount=0`. لهذا لا يمكن اختبار حساب إنتاجي الآن. يرفض الخادم التسجيل بـ`503 AUTH_NOT_CONFIGURED` قبل أي كتابة. لا تغيّر هذا إلى قاعدة مؤقتة.

1. وفّر `DATABASE_URL` لقاعدة Postgres دائمة و`BETTER_AUTH_SECRET` قويًا و`BETTER_AUTH_URL=https://waha.hajdah.com`، واجعل `VITE_AUTH_ENABLED` غير معطل (أو `true`). طبّق `migrations/auth/0001_auth.sql` وفق تعليمات المشروع. البريد/كلمة المرور لا يحتاجان أسرار موفر Google.
2. اختياريًا لـGoogle: وفّر `GROK_AUTH_CLIENT_ID` و`GROK_AUTH_CLIENT_SECRET` لعميل البيت الفعلي، واضبط callback `/api/auth/oauth2/callback/grok-google` لدى موفر OAuth. لا تستخدم أسرار عميل المعاينة على نطاق الإنتاج.
3. لاستعادة كلمة المرور: وفّر `RESEND_API_KEY` و`AUTH_EMAIL_FROM` لمرسل موثّق. Better Auth يصدر رمز الاستعادة؛ الخادم يرسل رابطه عبر Resend، ولا تظهر الرموز أو المفاتيح في العميل أو السجلات. غياب المرسل يعطل الاستعادة بوضوح دون ادعاء إرسال رسالة.
4. أعد النشر، ثم أنشئ حسابًا ببريد اختبار تملكه، وافحص الجلسة والدخول والخروج والتسجيل → الاهتمامات → يومي، ورسالة الاستعادة وتغيير كلمة المرور. احذف الحساب الاختباري وبياناته من قاعدة الاختبار بعد التحقق. لم يُنفّذ هذا الجزء لأن إعدادات الإنتاج غائبة.

الصفحة لا تدعي أعداد مستخدمين، ولا تصف الموجز الاستخراجي بأنه مولد بالذكاء الاصطناعي، ولا تعرض رابط متجر غير متوفر. اللقطات في `public/landing/` ملتقطة من صفحات واحة الحقيقية. صورة المشاركة القائمة `public/og.jpg` لهوية واحة، مع OG وTwitter وschema.org WebApplication.
