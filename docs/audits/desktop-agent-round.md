## الحفظ والاستعادة

التغيير محفوظ في Git فوق نقطة البداية المذكورة، مع package-lock والتكوين القائم. الاستعادة الآمنة للمراجعة: checkout للنسخة المطلوبة في worktree مستقل، ثم `npm ci` و`npm test` و`npm run build`. التراجع عن الجولة بعد الدمج يكون عبر `git revert` لكوميت الجولة مع حفظ أي عمل لاحق؛ لا force-push. المثبتات غير موقعة وتذهب لمسودة فقط؛ لا نشر ولا متجر.

حالة CI النهائية تُراجع عبر SHA كوميت الجولة في GitHub Actions؛ لا يُفهم من نجاح الاختبارات المحلية نجاح المثبتات.
